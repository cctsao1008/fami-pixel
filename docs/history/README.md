# Historical Documentation

This directory preserves milestone-era documentation for provenance.

These files may contain superseded planner versions, old validation status, temporary limitations, stale commands, or earlier architectural assumptions.

They are **not** the authority for current behavior.

Use current documentation under:

```text
docs/architecture/
docs/research/
docs/operations/
```

for the present system contract.

Historical records remain useful for reconstructing why a design changed and for correlating old GitHub issues, experiment logs, and regression discoveries.
